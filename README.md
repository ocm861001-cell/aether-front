# 에테르 전선 (AETHER FRONT)

설치 없이 브라우저에서 바로 즐기는 오리지널 MOBA 게임입니다. PC와 모바일(터치) 모두 지원합니다.

- 6종족 12챔피언: 솔라 기사단, 실반 엘프, 철피 오크, 공허 망자, 태엽 기계족, 화염 용인족
- 4개 전장: 에테르 협곡(5v5·3라인), 서리 다리(5v5·단일 라인), 사구 협곡(3v3·2라인), 잿불 화산섬(용암·운석)
- AI 봇 대전, 난이도 3단계, 상점 12종, 정글 보스, 전적 자동 저장

## 조작
| PC | 모바일 |
|---|---|
| 클릭: 이동·공격 | 왼쪽 조이스틱: 이동 |
| Q W E R: 스킬(마우스 방향) | 스킬 버튼 탭: 자동 조준 / 끌기: 직접 조준 |
| D 회복 · F 점멸 · B 귀환 · P 상점 · Tab 점수판 | 공격 버튼: 가까운 적 공격 |
